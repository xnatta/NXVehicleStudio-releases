# NX Vehicle Studio

ช่องดาวน์โหลดโปรแกรม Windows 11 x64 สำหรับ OBJ Vehicle Scene Editor / Phase 1

[ดาวน์โหลดรุ่นล่าสุด](https://github.com/xnatta/NXVehicleStudio-releases/releases/latest)

ติดตั้งสำหรับผู้ใช้ปัจจุบัน ใช้ Microsoft WebView2 Evergreen มี Bootstrapper ในตัวติดตั้ง เครื่องปลายทางไม่ต้องมี Node หรือ Rust แต่การติดตั้ง WebView2 ครั้งแรกต้องใช้อินเทอร์เน็ต

รองรับ OBJ/MTL/PNG/JPEG/WebP/BMP, หลาย Object/Group, Orbit/Pan/Zoom, Selection, Transform Gizmo, Undo/Redo, Project Save/Load (.nxv), Panel Resize และ Performance Monitor

ระบบอัปเดตใช้ HTTPS และลายเซ็น Tauri ก่อนติดตั้งจะบันทึก Recovery ไม่มี GTA Drawable/Rigging/YFT Export ใน Phase 1 ตัวติดตั้งยังไม่มี Authenticode certificate

Source Repository ของเจ้าของโปรเจกต์: [NXVehicleModel](https://github.com/xnatta/NXVehicleModel) (private)
